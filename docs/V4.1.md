# V4.1 — トップへ戻るときのBGM継続

## 原因と修正
左上のブランドリンクだけが通常の `href="/"` ナビゲーションになっており、文書全体の再ロードでaudio要素とAudioContextが破棄されていた。公開V4で、再生時刻19.58秒からタイトルを押すと0秒・paused=trueへ戻ることを再現。

通常の左クリック/キーボードによるリンク操作は既存lobby処理へ流し、Reactツリー内で画面を切り替える。同じaudio要素・AudioContextを維持する。トップへの移動時はダイアログを閉じて先頭へスクロール。修飾キー付きクリック・新規タブ操作は通常のリンク動作を維持。

BGMの初回OFF、音量、背景タブでの一時停止、明示的OFFの仕様は変更しない。ブラウザ再読み込み、タブ終了、外部ログイン/ログアウトへの文書遷移中の継続は対象外。ゲームルール、認証、DBスキーマに変更なし。

## 復旧
`release/v0.4.0` と `docs/RELEASE-V4.json` の保存済みSites版を再デプロイする。V4.1は表示/ナビゲーションのみなので、V4への復旧に部屋整理やDB変更は不要。

## 検証・公開結果
既存25テスト・型チェック・ビルドPASS。ローカルで部屋からタイトルをクリックすると7.33秒→7.41秒、部屋への再入室/ロビーへ戻る/Enterキーでは15.76→15.81→15.88秒と継続し、全てpaused=false。変更した音量20%も維持。OFFにして往復した場合はpaused=trueを維持。

V4.1を同じURLに公開し、公開版のタイトル移動も13.37秒→13.45秒、paused=falseで確認。確認後はBGMをOFFへ戻し、ローカルサーバーを終了。公開ソースのGitタグはrelease/v0.4.1。Sitesの保存順番号は5だが、ゲームの呼称/バージョンはV4.1/v0.4.1（V5ではない）。識別子はRELEASE-V4.1.json参照。

Discord向け貼付用文章はDISCORD-V4.1.txt。外部チャットへの送信は行っていない。
