## ローカルHTTP試験の再実行

`npm start -- --port 8787` と、初期化済みのローカルD1が必要。スクリプトは固定のループバックURLだけに接続する。`.sites-runtime/` の状態はGit・公開物から除外。

```sh
node scripts/qa-http.mjs setup
node scripts/qa-http.mjs play
```

既存のローカルテスト部屋が終了済みなら、開発UIから待機室に戻してからsetupを実行する。スクリプトの人物は合成テスト用であり、実際のChatGPT複数アカウントによる試験ではない。

## 発生して解消した問題

Documents配下の依存ファイルのdataless化で、Miniflare起動失敗や一時的な開発サーバー再起動が発生。依存を同期外へ再インストールし、使っていないstarter UIをビルド対象から除外して復旧した。これ以前の失敗をアプリ側のPASSと混同しない。
