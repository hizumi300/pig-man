# v0.3.0 — BGM・表示設定・名前の長さ

2026-11-04。ユーザーからV2の好評を受領し、BGM、8文字の名前制限、文字サイズ切替を追加。BGMは追加指示に従い、ダークな世界観を採用。

## 変更

- BGM「影の豚小屋」: 76 BPM、約50.53秒。低い弦風の和音、低音の脈動、余韻のある鐘を使うオリジナル曲。`scripts/compose-bgm.mjs` に楽譜と音の合成処理を保存。外部曲・録音サンプル・音楽配信サービスは使用しない。
- 112kbpsステレオMP3、708,459 bytes。ユーザーがBGMを押した時だけ読込・再生。初期OFF、音量25%。背景タブでは停止し、再び表示すると有効時だけ再開する。Web AudioのGainNodeで音量を調整し、設定値を端末に保存。ゲーム操作は音楽の読込失敗に影響されない。
- 文字サイズは小90%・標準100%・大115%・特大130%。画面上部に追従する操作欄から変更し、標準へ1回で戻せる。文字サイズだけを変更し、カード寸法を拡大しない。設定は端末に保存。
- 新しく設定する表示名は1〜8文字。NFKC正規化後の書記素単位で数え、日本語・絵文字・結合文字を扱う。画面のカウンターとサーバーの作成・参加・観戦で同じ判定を使用。IME入力中に強制切断せず、9文字以上は送信不可とする。
- 既に保存されている長い名前は勝手に改名せず、席・役職・再接続を維持する。既存の対戦ルール、ChatGPT認証、公開範囲、DBスキーマ、6時間の期限は変更しない。

## 復旧と再生成

復旧先は [RELEASE-V2.json](RELEASE-V2.json) のSites Version 2と、Gitタグ `release/v0.2.0`（`b09a19eaaad4d4cbc2bade072710f7763283d5ca`）。新しいブランチは `codex/bgm-accessibility-v3`。DBの移行や本番での復旧試験は不要。保存済みV2を同じSiteへ再デプロイする。

BGMの再生成だけは、既にインストールされているffmpegを使い `node scripts/compose-bgm.mjs` を実行する。通常のビルド・公開・ゲーム利用にはffmpegは不要。生成MP3をGitと公開アセットに含める。

```sh
npm test
npm run typecheck
node --experimental-strip-types scripts/qa-rollback.mjs
```
