## 試験中の失敗と限界

- 最初の配役テストは連番LCGシードの最初の値が偏り、両方の配役を網羅できなかった。シードを分散し、シャッフル結果の完全一致と全可能人数を検証。実装側の乱数処理は変更していない。
- ローカルHTTP setupが前回終了済み部屋で開始しようとして409になった。終了済みの合成テスト部屋を待機室に戻してから開始するよう試験スクリプトを修正。
- 内蔵ブラウザへの接続が利用できず、Chromeで表示を確認。終局直前の公開盤面保持は観測できたが、数秒間のラウンド切替・反転アニメーションを確実に捕捉する自動ブラウザ検証は、ブラウザ接続のタイムアウトにより未完了。APIの待機期限・盤面保持・再配布回数はテストで検証済み。
- この新版について、実際の別々のChatGPTアカウント3人による公開後の対戦・実機の触感は未確認。Version 1のユーザー報告を新版の実機PASSとして扱わない。
- DBマイグレーション・公開DBを使った試験・本番を旧版に戻す試験は行っていない。期限切れ行の物理削除は次回の部屋作成時であり、無アクセス時の6時間ちょうどの削除を保証しない。

## 再実行

```sh
npm test
npm run typecheck
node --experimental-strip-types scripts/qa-rollback.mjs
```

ビルド済みWorkerをlocalhost:8787で起動し、初期化済みのローカルD1で `node scripts/qa-http.mjs setup` → `node scripts/qa-http.mjs play`。`chat` / `step` はブラウザ確認用の合成投稿・1手進行。全モードで宛先はループバック固定。本番へは使わない。

復旧先と制約は [PLAYER-FEEDBACK-V2.md](PLAYER-FEEDBACK-V2.md)、固定済みVersion 1の識別子は [ROLLBACK-V1.json](ROLLBACK-V1.json) を参照。
